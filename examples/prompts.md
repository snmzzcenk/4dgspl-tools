# Example requests

Give any of these to Claude Code, Codex or another coding agent working in an empty folder. The agent reads https://4dgspl.at/en/agents.html (or AGENTS.md in this repository) and does the rest.

- "Make a 4D Gaussian Splatting video of a Mixamo character doing a hip-hop dance, ready to upload to 4dgspl.at."
- "Turn the animation in `robot.blend` into a 4DGS scene with 4dgspl.at: 8 cameras, black background, validate before upload."
- "I want a stylized red-dressed dancer I can watch from any angle in the browser. Build it in Blender and prepare the 4dgspl.at upload."
- Türkçe: "Mixamo'dan dans eden bir karakter seç, 4dgspl.at için 8 kameralı render ve kalibrasyonu hazırla, yüklemeden önce denetle."

For a fully specified brief, with camera count, duration, resolution and fps chosen in a form, use the prompt generator: https://4dgspl.at/en/capture.html#ai (Turkish: https://4dgspl.at/cekim.html#yz).
